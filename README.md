***Java v/s C#***
Ans. 

**Java**
Java is a safely typed language i.e. it does not support pointers.
Java does not support static constructors.
Java uses Java runtime environment (JRE) to run programs.

**C#**
C# is an unsafe language i.e it supports the use of pointers.
C# supports static constructors.
C# uses CLR (Common Language Runtime) to run programs. 

***What is JIT***
Ans. First any language specific compiler converts the written code into MSIL, when the code needs to be executed, JIT (Just in time compiler) converts the MSIL(Microsoft intermediate language) into machine code which can then be executed.

***CLR v/s CIL***
Ans. **CLR(Common Language Runtime)** it loads, locates and manages resources. It also helps in memory management and security.
**CIL(Common Intermediate Language)** it is created by a language specific compiler and when a program needs to be executed then it is converted to machine code by JIT.

***.NET  SDK v/s .NET Runtime*** 
Ans. **.NET SDK (Software Development Kit)** - provides the tools which are necessary to build a .NET application such as libraries and compiler.
**.NET Runtime** provides the environment needed to run a compiled application of .NET. It consists of components like 
garbage collector, JIT Compiler, CLR(Common Language Runtime).
